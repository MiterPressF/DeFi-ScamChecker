## User Guide: Smart Contract Security Auditing Loop
Step 1: Target Network Selection Click on the drop-down menu (1) to select the trading platform or blockchain network deployment layer where the contract or target asset resides (e.g., Ethereum Mainnet, Binance Smart Chain, or Arbitrum L2).

Step 2: Provide Smart Contract Address Input or paste the specific cryptographic contract address starting with 0x... into the dedicated text field (2). Ensure the address matches the network layer selected in the first step.

Step 3: Initiate the Inspection Engine Click the "AUDIT ASSET" compilation button (3). This triggers the asynchronous backend pipeline to fetch on-chain primitives, pull unverified bytecode via JSON-RPC gateways, and pass parameters to the deterministic multi-criteria scoring matrix.

Step 4: Evaluate Verdict Metrics Observe the dynamically rendered security scale and final index output (4). The presentation layer will immediately display the calibrated Trust Score along with a color-coded classification status: SAFE (Green), WARNING (Yellow), or SCAM (Red).
